# HygieneCare – HTML/CSS/JavaScript recreation

## Run in VS Code
1. Extract this folder.
2. Open the `HygieneCare_Website` folder in VS Code.
3. Open `index.html`.
4. Install the **Live Server** extension if needed.
5. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Files
- `index.html` – page structure and content
- `styles.css` – responsive styling
- `script.js` – disease cards/filter/details, mobile navigation, local image preview and 10-question quiz

## Important notes
This is an independently written recreation based on the public-facing content visible on the supplied HygieneCare URL. It is not the original Lovable source export and is not guaranteed pixel-identical. The skin scanner is an interface demo only: it previews an image locally and does not run AI analysis or diagnose disease. The disease information is educational; consult a qualified healthcare professional for medical advice.

Google Fonts are loaded online. If you want fully offline fonts, remove the Google Fonts links from `index.html` and the `@import` line in `styles.css`.
